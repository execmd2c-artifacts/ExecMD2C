## Reproduction task

The model segments organs from a few annotated examples using prototypes and regularized neural ODEs. In `template.py`, complete `FewShotSeg.forward`, `ODEBlock.forward`, and the other TODO-marked functions to run one prototypical few-shot segmentation episode and integrate the ODE dynamics from the initial feature state to the configured final time.
