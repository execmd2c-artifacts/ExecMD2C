## Reproduction task

The geometric latent diffusion model generates 3D molecular structures. In `template.py`, complete `GCL.edge_model`, `EnVariationalDiffusion.sample_combined_position_feature_noise`, and the other TODO-marked functions to compute invariant edge messages for the graph convolution layer and sample masked geometric and feature noise for the diffusion latent.
