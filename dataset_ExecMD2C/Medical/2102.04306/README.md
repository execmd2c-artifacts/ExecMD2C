## Reproduction task

TransUNet combines transformer encoders and convolutional decoders for medical image segmentation. In `template.py`, complete `StdConv2d.forward`, `VisionTransformer.load_from`, and the other TODO-marked functions to apply a standardized convolution used by the ResNetV2 stem and bottlenecks and load pretrained ViT and optional hybrid ResNet weights into the TransUNet model.
