# Deep Convolutional Neural Networks for Breast Cancer Histology Image Analysis (1802.00752)

## Project source

- **Project ID:** `1802.00752`
- **Paper:** Deep Convolutional Neural Networks for Breast Cancer Histology Image Analysis
- **PDF:** http://arxiv.org/pdf/1802.00752v2.pdf
- **GitHub:** https://github.com/alexander-rakhlin/ICIAR2018

## Reproduction task

The model classifies breast-cancer histology images with deep convolutional networks. In `template.py`, complete `ResNet.predict`, `Inception.predict`, and `VGG.predict` to encode image crops with the ResNet feature extractor and encode image crops with the multi-layer VGG descriptor model.
