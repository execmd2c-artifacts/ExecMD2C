## Reproduction task

AutoCoder improves code-language-model training with executable instruction data. In `template.py`, complete `BaseCodeInterpreter.execute_code_and_return_output`, `JupyterNotebook.clean_output`, and the other TODO-marked functions to write generated code to the sandbox, optionally install packages, and return Docker execution output and convert raw Jupyter message payloads into a compact text response.
