## Reproduction task

The benchmark network implements distributional Atari agents used to study reinforcement learning with latent flow. In `template.py`, complete `noisy_linear`, `c51_atari_network`, and the other TODO-marked functions to build a Haiku-compatible factorized NoisyNet linear layer and build the C51 Atari categorical value-distribution network.
