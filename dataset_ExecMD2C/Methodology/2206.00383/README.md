## Reproduction task

The model improves candidate solutions to graph combinatorial optimization problems. In `template.py`, complete `GNNLayer.forward`, `Model.forward`, and the other TODO-marked functions to run one anisotropic GNN update layer over node and edge embeddings and run the neural improvement policy for PRP, TSP, or GPP instances.
