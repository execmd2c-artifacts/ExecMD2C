## Reproduction task

PaDGAN generates diverse designs while favoring high-performing outputs. In `template.py`, complete `BaseModel.compute_diversity_loss`, `BezierGAN.compute_diversity_loss`, and the other TODO-marked functions to build the synthetic PaDGAN performance-augmented DPP objective and build the airfoil PaDGAN performance-augmented DPP objective.
