## Reproduction task

The Transformer Hawkes Process models the timing and type of events in a sequence. In `template.py`, complete `ScaledDotProductAttention.forward`, `log_likelihood`, and the other TODO-marked functions to compute scaled dot-product attention with optional masking and compute event and non-event log-likelihood terms for a THP sequence.
