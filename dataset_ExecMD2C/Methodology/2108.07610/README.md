## Reproduction task

DRAEM detects surface defects by comparing reconstructed and observed images. In `template.py`, complete `ReconstructiveSubNetwork.forward`, `DecoderReconstructive.forward`, and the other TODO-marked functions to run the reconstructive DRAEM sub-network forward pass and decode the reconstructive bottleneck back to an image tensor.
