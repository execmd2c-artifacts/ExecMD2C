## Reproduction task

Frozen in Time retrieves videos and images using joint visual and text encoders. In `template.py`, complete `VarAttention.forward`, `FrozenInTime._inflate_positional_embeds`, and the other TODO-marked functions to reproduce the variable space/time attention used by the Space-Time Transformer and adapt positional embeddings when loading pretrained checkpoints.
