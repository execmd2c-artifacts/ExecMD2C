## Reproduction task

CLIP4Clip retrieves video clips for natural-language queries using CLIP representations. In `template.py`, complete `CLIP4Clip._get_cross_output`, `CLIP4Clip.get_similarity_logits`, and the other TODO-marked functions to build and run the tight cross-transformer input for one text-video batch and dispatch to the correct CLIP4Clip similarity head.
