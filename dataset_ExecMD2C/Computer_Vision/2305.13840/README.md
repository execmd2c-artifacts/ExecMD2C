## Reproduction task

Control-A-Video generates videos from text while following control signals and motion priors. In `template.py`, complete `PseudoConv3d.forward`, `ControlNetInputHintBlock.forward`, and `ControlNetPseudoZeroConv3dBlock.forward` to reproduce the pseudo-3D convolution forward pass and reproduce the ControlNet zero-convolution residual projection block.
