## Project source

- **Project ID:** `2308.09091`

- **PDF:** https://arxiv.org/pdf/2308.09091v2.pdf
- **GitHub:** https://github.com/mdswyz/TCVE

## Reproduction task

TCVE edits videos with an image diffusion backbone and temporal consistency modules. In `template.py`, complete `Transformer3DModel.forward`, `UNet3DConditionModel.from_pretrained_2d`, and the other TODO-marked functions to reproduce the source TCVE video transformer wrapper and reproduce the source TCVE 2D-to-3D checkpoint loading method.
