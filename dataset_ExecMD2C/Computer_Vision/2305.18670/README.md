## Reproduction task

SAVE adapts image diffusion models for text-guided video editing with spectral-shift-aware layers. In `template.py`, complete `SVDConv2d.forward`, `SVDLinear.forward`, and `SVDEmbedding.forward` to reproduce the SAVE SVD-parameterized 2D convolution forward pass and reproduce the SAVE SVD-parameterized embedding lookup.
