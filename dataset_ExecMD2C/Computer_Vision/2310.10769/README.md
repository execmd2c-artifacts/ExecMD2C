## Reproduction task

LAMP learns motion patterns from a few examples to generate videos. In `template.py`, complete `Transformer3DModel.forward`, `UNet3DConditionModel.from_pretrained_2d`, and the other TODO-marked functions to reproduce the source LAMP video transformer wrapper and reproduce the source LAMP 2D-to-3D checkpoint loading method.
