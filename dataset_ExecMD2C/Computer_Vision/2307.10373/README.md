## Reproduction task

TokenFlow edits videos consistently by propagating diffusion features across frames. In `template.py`, complete `register_conv_injection`, `make_tokenflow_attention_block`, and the other TODO-marked functions to run the injected ResNet convolution path used by TokenFlow PnP and run a TokenFlow transformer block with pivotal-token propagation.
