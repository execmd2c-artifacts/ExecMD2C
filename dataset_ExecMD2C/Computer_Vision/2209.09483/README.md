## Reproduction task

The model segments 3D point clouds with diffusion-based edge enhancement and suppression. In `template.py`, complete `DepthwiseKPConv.forward`, `DiffusionUnit.forward`, and `SceneSegNet.forward` to reproduce the depthwise kernel point convolution forward pass and reproduce the scene segmentation encoder-decoder forward pass.
