# STGODE (2106.12931)

## Project source

- **Project ID:** `2106.12931`
- **Paper:** Spatial-Temporal Graph ODE Networks for Traffic Flow Forecasting
- **PDF:** https://arxiv.org/pdf/2106.12931v1.pdf
- **GitHub:** https://github.com/square-coder/STGODE

## Reproduction task

STGODE forecasts traffic flow by modeling spatial and temporal dependencies with graph ordinary differential equations. In `template.py`, complete `ODEFunc.forward`, `STGCNBlock.forward`, and `ODEGCN.forward` to implement the graph dynamics, the temporal–ODE block, and the final forecast from spatial and semantic branches.
