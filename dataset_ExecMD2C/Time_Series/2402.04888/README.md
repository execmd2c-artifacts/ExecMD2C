# RSCNet: Dynamic CSI Compression for Cloud-based WiFi Sensing (2402.04888)

## Reproduction task

RSCNet compresses WiFi channel-state information while preserving sensing accuracy. In `template.py`, complete `RecurrentBlock.forward` to propagate compressed CSI windows through the recurrent state.
