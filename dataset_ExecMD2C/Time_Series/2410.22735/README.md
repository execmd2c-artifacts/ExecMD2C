## Reproduction task

MIXAD detects and explains time-series anomalies using memory-induced representations. In `template.py`, complete `GC.forward`, `MIXAD.forward`, and the other TODO-marked functions to apply Chebyshev graph convolution over the learned graph supports and run the full MIXAD encoder-memory-decoder reconstruction pipeline.
