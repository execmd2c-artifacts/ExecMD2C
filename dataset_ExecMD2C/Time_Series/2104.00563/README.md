## Reproduction task

AutoBots predicts multiple agents' future trajectories jointly with latent-variable set transformers. In `template.py`, complete `MapEncoderPtsMA.get_road_pts_mask`, `nll_loss_multimodes_joint`, and the other TODO-marked functions to build road segment and road point masks for multi-agent lane sets and compute the AutoBot-Joint multimodal latent-variable training objective.
