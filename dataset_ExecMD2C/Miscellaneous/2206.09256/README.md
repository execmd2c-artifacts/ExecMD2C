# Multistream Gaze Estimation with Anatomical Eye Region Isolation by Synthetic to Real Transfer Learning (2206.09256)

## Project source

- **Project ID:** `2206.09256`
- **Paper:** Multistream Gaze Estimation with Anatomical Eye Region Isolation by Synthetic to Real Transfer Learning
- **PDF:** https://arxiv.org/pdf/2206.09256v2.pdf
- **GitHub:** https://github.com/z-mahmud22/MSGazeNet

## Reproduction task

The model estimates gaze from multiple image streams after isolating the eye region. In `template.py`, complete `AERI_UNet.forward` and `MSGazeNet.forward` to run the AERI U-Net segmentation path for anatomical eye-region isolation and run the MSGazeNet multistream gaze-estimation forward pass.
