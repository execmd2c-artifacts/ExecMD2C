- **PDF:** https://arxiv.org/pdf/2106.02817v1.pdf

## Reproduction task

ImGAGN learns embeddings for imbalanced graphs with an adversarial generator. In `template.py`, complete `GraphConvolution.forward`, `GCN.forward`, and `Generator.forward` to apply one graph convolution layer for ImGAGN's GCN discriminator/classifier and generate bounded synthetic-minority relation weights from random noise.
