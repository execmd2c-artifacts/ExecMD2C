## Reproduction task

MESA trains ensembles on imbalanced data with a learned meta-sampler. In `template.py`, complete `meta_sampling`, `GaussianPolicy.sample`, and the other TODO-marked functions to perform MESA's action-conditioned majority-class meta-sampling and sample a bounded SAC action from the Gaussian meta-sampler policy.
