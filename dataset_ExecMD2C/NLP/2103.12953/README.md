## Reproduction task

SCCL clusters text representations with a contrastive learning objective. In `template.py`, complete `target_distribution`, `SCCLBert.contrast_logits`, and the other TODO-marked functions to build SCCL's sharpened clustering target distribution and project SCCL embeddings for instance-level contrastive learning.
