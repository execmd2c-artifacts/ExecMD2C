## Reproduction task

DFTS2 transmits deep features across packet-loss channels and reconstructs missing information. In `template.py`, complete `PacketModel.dataToPacket`, `fn_caltec`, and the other TODO-marked functions to convert the 4-D feature tensor into a 5-D DFTS packet sequence and repair lost DFTS packets using the CALTeC correlation-and-transform rule.
