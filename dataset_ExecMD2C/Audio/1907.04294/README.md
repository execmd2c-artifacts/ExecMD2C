## Reproduction task

The model recognizes musical instruments by attending to informative moments in an audio recording. In `template.py`, complete `Attention.forward`, `EmbeddingLayers.forward`, and `DecisionLevelSingleAttention.forward` to compute decision-level attention pooling over time and run the complete decision-level attention model.
