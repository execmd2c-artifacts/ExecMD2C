## Reproduction task

VocBench compares neural vocoder architectures that generate speech waveforms from acoustic features. In `template.py`, complete `CausalConv1d.forward`, `ResidualParallelWaveGANDiscriminator.forward`, and the other TODO-marked functions to apply the causal 1-D convolution and run the residual Parallel WaveGAN discriminator.
