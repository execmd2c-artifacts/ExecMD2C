## Reproduction task

The model compares graphs while preserving information privacy. In `template.py`, complete `MessageExtraction.forward`, `PPGM.global_aggregation_info`, and `PPGM.forward` to extract graph-level messages with learnable or external queries and run PPGM on a pair of graphs and produce similarity or messages.
