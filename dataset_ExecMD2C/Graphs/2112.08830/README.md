- **Project ID:** `2112.08830`

## Reproduction task

The model learns graph representations by extracting factors shared across graphs without labels. In `template.py`, complete `Summary_Maker.forward`, `Encoder.forward_diff`, and `deepGCFX.forward` to iteratively extract graph-wise common latent factors and split node information and compute the deepGCFX graph-level unsupervised training objective.
