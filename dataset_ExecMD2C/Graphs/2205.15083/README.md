## Reproduction task

CGMN learns graph similarity through contrastive matching of graph representations. In `template.py`, complete `HierarchicalGraphMatchNetwork.cosine_attention`, `HierarchicalGraphMatchNetwork.matching_layer_g1g2`, and the other TODO-marked functions to compute pairwise cosine attention between two batched node-feature sequences and compute graph-level pair features from node-graph matching.
