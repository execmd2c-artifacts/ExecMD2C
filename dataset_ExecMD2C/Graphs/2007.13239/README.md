## Reproduction task

funcGNN estimates program similarity by comparing their graph representations. In `template.py`, complete `AttentionModule.forward`, `TenorNetworkModule.forward`, and `funcGNN.forward` to reproduce the source graph-level attention pooling operation and reproduce the full graph-pair similarity forward pass.
