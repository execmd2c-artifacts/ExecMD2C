## Reproduction task

The model recognizes places from 3D point clouds using semantic graph representations. In `template.py`, complete `AttentionModule.forward`, `SG.forward`, and the other TODO-marked functions to pool batched node embeddings into graph-level representations and score a batch of semantic graph pairs.
