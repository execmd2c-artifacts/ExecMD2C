The system studies instruction tuning with symbolic tasks, including table-based inputs. In `template.py`, complete `preprocess_function_with_template`, `TableProcessor.process_output`, and the other TODO-marked functions to render symbolic instruction inputs from declared fields and tokenize inputs/targets and flatten a list of answer strings into the model target string.
