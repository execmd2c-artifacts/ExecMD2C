## Reproduction task

The model combines short-term, episodic, and semantic memory for sequence learning. In `template.py`, complete `LSTM.make_embedding`, `LSTM.create_batch`, and `LSTM.forward` to convert one explicit memory quadruple into a neural embedding and encode selected memory systems and produce DQN action values.
