ITI-GEN makes text-to-image generation more inclusive across protected attributes. In `template.py`, complete `FairToken.forward`, `ITI_GEN.iti_gen_loss`, and the other TODO-marked functions to return the learnable FairToken parameter and compute the fairness-guidance loss across attribute categories.
