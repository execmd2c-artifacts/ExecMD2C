## Reproduction task

The model aligns entities across temporal knowledge graphs without labeled correspondences. In `template.py`, complete `OverAll.forward` and `GraphAttention.forward` to assemble DualMatch entity, relation, and time representations and propagate entity features through relation- or time-aware graph attention.
