# SimNet: Enabling Robust Unknown Object Manipulation from Pure Synthetic Data via Stereo (2106.16118)

## Project source

- **Project ID:** `2106.16118`

- **PDF:** https://arxiv.org/pdf/2106.16118v1.pdf
- **GitHub:** https://github.com/ToyotaResearchInstitute/simnet

## Reproduction task

SimNet predicts object geometry and pose from stereo imagery for unknown-object manipulation. In `template.py`, complete `NetFactory.forward`, `PanopticNet.forward`, and the other TODO-marked functions to execute the baked graph of convolution, residual, upsample, and tag nodes and run the full SimNet multi-task forward pass.
