## Reproduction task

SpaGBOL localizes an agent using spatial graphs and oriented observations. In `template.py`, complete `ConvNextExtractor.embed_map`, `FullModel.walk_step`, and the other TODO-marked functions to embed satellite/map image tiles with the map ConvNeXt branch and run one SpaGBOL graph-walk step for train, validation, or test.
