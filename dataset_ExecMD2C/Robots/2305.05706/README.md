## Reproduction task

DexArt learns representations for dexterous manipulation of articulated objects. In `template.py`, complete `PointNet.forward`, `PointNetImaginationExtractorGP.forward`, and the other TODO-marked functions to encode an unordered point cloud into one global 256-dimensional feature vector per batch item and fuse observed point clouds, imagination point clouds, and optional robot state features.
