## Reproduction task

The transformer estimates scale in monocular visual odometry from visual features. In `template.py`, complete `forward_vit`, `DPTDepthModel.forward`, and the other TODO-marked functions to run the adapted ViT backbone and reassemble four hooked activations into image-like feature maps and convert the base DPT dense prediction into inverse depth or metric-like depth.
