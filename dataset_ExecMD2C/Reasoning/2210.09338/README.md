The model pretrains language and knowledge-graph representations bidirectionally. In `template.py`, complete `GATConvE.forward`, `RotatEDecoder.score`, and the other TODO-marked functions to run DRAGON's typed edge/node graph attention layer and score triples with RotatE complex-space relation rotations.
