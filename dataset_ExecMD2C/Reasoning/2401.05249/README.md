## Reproduction task

CASA assesses whether arguments contain enough evidence through causal claim analysis. In `template.py`, complete `select_prompt_format`, `estimate_probability_predictions`, and the other TODO-marked functions to select the CASA prompt template for a model family and task stage and estimate CASA sufficiency from NLI-style context/conclusion scores.
