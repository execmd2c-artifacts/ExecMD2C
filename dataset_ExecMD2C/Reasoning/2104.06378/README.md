## Reproduction task

QA-GNN answers questions by reasoning jointly over language and knowledge graphs. In `template.py`, complete `MatrixVectorScaledDotProductAttention.forward`, `QAGNN.forward`, and the other TODO-marked functions to compute masked scaled attention from one query vector over a sequence and run the full QA-GNN decoder from sentence vectors and concept graph inputs to logits.
