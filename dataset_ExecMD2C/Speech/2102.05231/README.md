## Reproduction task

The model generates culture-inspired color palettes and colorized images from text and categories. In `template.py`, complete `T2PGenerator.call`, `ColorizationDiscriminator`, and the other TODO-marked functions to generate one RGB palette color from noise and multimodal context and build the context-conditioned image discriminator.
