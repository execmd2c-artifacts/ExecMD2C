## Reproduction task

AraSpot recognizes Arabic spoken commands with a Conformer-based network. In `template.py`, complete `FeedForwardModule.forward`, `ConformerGRU.forward`, and the other TODO-marked functions to reproduce the Conformer feed-forward residual branch and reproduce the top-level ConformerGRU classifier path.
