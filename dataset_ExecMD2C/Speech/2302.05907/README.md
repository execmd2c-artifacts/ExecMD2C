## Reproduction task

LipLearner recognizes customizable silent speech commands from mobile video. In `template.py`, complete `BasicBlock.forward`, `VideoModel.forward`, and the other TODO-marked functions to reproduce the ResNet BasicBlock with optional SE gating and reproduce the LipLearner top-level video encoder.
