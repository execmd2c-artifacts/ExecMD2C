## Project source

- **Project ID:** `2010.04062`

- **PDF:** https://arxiv.org/pdf/2010.04062v1.pdf

## Reproduction task

MIA-Prognosis predicts clinical therapy response from irregular medical time series. In `template.py`, complete `SimTALayer._get_attn_matrix`, `SimTANet.forward`, and the other TODO-marked functions to build the SimTA cumulative time-interval attention matrix and reproduce the end-to-end SimTA regression model.
